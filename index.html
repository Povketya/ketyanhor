Machine Learning · Featured

Explainable AI for Diabetes Risk Prediction and Actionable Insights

Academic Project

Developed and evaluated machine-learning models for diabetes-risk prediction using BRFSS and Cambodia STEPS health data.

PythonPandasNumPyScikit-learnXGBoostLightGBMCatBoostSHAPStreamlit

Problem

Support risk prediction while accounting for external validation, class imbalance, interpretable output, and practical risk communication.

My role

Data preparation, model evaluation, explainability analysis, and Streamlit application development.

Dataset

BRFSS and Cambodia STEPS health data. Variables were prepared and aligned for model development and external validation.

Data preparation

Aligned datasets, prepared model inputs, and addressed class imbalance through class weighting and decision-threshold optimization.

Methodology

Evaluated Logistic Regression, Random Forest, XGBoost, LightGBM, CatBoost, and a Soft Voting Ensemble using accuracy, precision, recall, F1-score, and other classification measures.

Results & output

Produced global and individual explanations with SHAP and a Streamlit interface presenting probability, risk level, contributing factors, and actionable recommendations. No unverified model score is published here.

Practical impact

Demonstrates how predictive output can be communicated more transparently. This portfolio project is not a medical diagnostic tool.

Challenges

Cross-dataset alignment, external validation, imbalanced classes, decision-threshold selection, and understandable risk communication.
